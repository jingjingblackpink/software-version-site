🚀 发布指南：让线上网站显示最新数据

方法零（最简单）：后台一键发布 ⭐推荐

先在【⚙️ 发布设置】里保存一次 GitHub Token，之后每次改完数据直接点 【🚀 一键发布】，其他设备 1~2 分钟内自动看到最新数据。

方法一（备用）：网页手动更新

1. 点击【📤 导出 data.js】下载最新数据文件；

2. 打开 GitHub 仓库 → 进入 data.js 文件 → 点右上角铅笔（编辑）；

3. 全选删除原内容，粘贴新文件的全部内容；

4. 点 Commit changes 提交，等待约 1 分钟，线上自动更新。

方法二：GitHub Desktop / 命令行

把导出的 data.js 放进本地仓库文件夹，提交并推送（git add / commit / push）即可。

💡 提示：后台的修改先保存在"你自己的浏览器"里；只有更新了 GitHub 仓库中的 data.js，其他人才能看到最新数据。

⚙️ 一键发布设置

首次使用需创建一个 GitHub Token（相当于发布密码）：

1. 点下方按钮打开 GitHub Token 创建页（已自动勾选 repo 权限）

2. 拉到页面底部点 Generate token，复制 ghp_ 开头的令牌

3. 粘贴到下方输入框 → 点【保存设置】→ 以后每次点【🚀 一键发布】即可

🔑 去创建 Token

🔒 Token 只保存在你自己的浏览器里，不会写入网站代码；泄露了到 GitHub 撤销即可。
