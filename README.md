# 软件版本管理网站

一个**纯静态**（HTML + CSS + JavaScript）的软件版本信息展示与管理系统，托管于 GitHub Pages，无需服务器和数据库。

## ✨ 功能

- 🔐 双角色登录：管理员后台（可增删改项目）+ 客户端页面（只读浏览）
- 📋 表格展示：项目名称、上传日期、版本信息、README 信息、下载链接
- ⬇ 下载链接指向百度网盘分享（建议带提取码）
- 📖 README 信息弹窗查看，支持多行文本
- 🔍 客户端实时搜索 / 筛选
- 📤 后台一键导出 `data.js`，替换仓库文件即可全站更新

## 📁 目录结构

```
├── index.html      登录页（入口）
├── admin.html      管理后台（管理员登录后进入）
├── client.html     客户端页面（只读浏览）
├── data.js         项目数据文件（核心数据）
├── css/style.css   全站样式
├── js/common.js    公共逻辑（账号、数据读写）
├── js/admin.js     后台逻辑
└── js/client.js    客户端逻辑
```

## 🚀 部署（GitHub Pages）

1. 将本仓库全部文件上传到你的 GitHub 仓库（Public）
2. 仓库 **Settings → Pages → Build and deployment**
3. Branch 选择 `main`，目录选择 `/(root)`，点击 **Save**
4. 约 1~2 分钟后访问：`https://<你的用户名>.github.io/<仓库名>/`

## 🔄 日常更新数据

1. 用管理员账号登录后台
2. 新增 / 编辑 / 删除项目
3. 点击【📤 导出 data.js】下载最新数据文件
4. 在 GitHub 仓库中打开 `data.js` → 编辑 → 全选替换为新文件内容 → Commit
5. 等待约 1 分钟，线上自动生效

> 提示：后台的修改先保存在浏览器本地，只有更新了仓库中的 `data.js`，其他人才能看到最新数据。

## ⚠️ 说明

- 登录校验在浏览器前端完成，适合个人 / 小团队分享场景，请勿存放敏感内容
- 修改账号密码请编辑 `js/common.js` 顶部的 `USERS` 配置
- 请确保百度网盘分享链接有效并附带提取码
